# wonder

Explainer decks made with the [wonder skill](https://github.com/DoojinBaek/wonder-skill), published at https://doojinbaek.github.io/wonder/.

This folder is a Wonder repo for the skill: `index.html` lists the decks and each deck lives in `topics/<date>-<slug>-deck/` (`deck.html`, `deck-edit.js`, `assets/`). Run the skill from inside this folder and it adds new decks to `topics/` and to the list in `index.html`.

To keep the repo small (GitHub Pages allows 1 GB per site):

- Save figures in `assets/` as WebP or JPEG, about 1600 px wide, rather than large PNGs or GIFs.
- Use MP4 or WebM for animations. A GIF is often several times larger.
- Git keeps every version of a file, so replacing an image does not free the old one. Text edits to `deck.html` cost little.
